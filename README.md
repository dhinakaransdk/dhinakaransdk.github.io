# Dhinakaran — Personal static site

This is a minimal single-page static site scaffold for Dhinakaran (Founder of EvyxAi). It's designed to be a nerdy/techy one-page portfolio you can host anywhere (GitHub Pages, Netlify, Vercel, or your own server).

Quick preview (PowerShell):

```powershell
# from project folder
Set-Location 'C:\Users\Dhinakaran\Desktop\projects\dhinakaran.online'

# Start a simple static server (Python 3 required)
python -m http.server 8080

# then open http://localhost:8080 in a browser
```

Files:
- `index.html` — main page
- `styles.css` — styling
- `script.js` — tiny terminal animation + dynamic year
